# Аналіз фіч: що є в схожих іграх

Дивились на оригінальну настільну «Бункер» (картки характеристик + картки
особливих умов), її офіційний companion-застосунок, браузерні клони та
загальні патерни онлайн party-ігор (Codenames, Spyfall, skribbl.io,
Jackbox, UNO/Bang-хаби з кімнатами за посиланням).

## Що зроблено в цьому оновленні

| Фіча | Звідки ідея | Як реалізовано |
|---|---|---|
| Посилання-запрошення + «Поділитись» | Майже всі party-ігри: «надішли лінк друзям» замість диктування коду | `/join?code=…`, `navigator.clipboard` / `navigator.share` у лобі |
| Сторінка правил | Кожен онлайн-клон має «Як грати»; нові гравці не знають настолки | `/rules`, prerender + sitemap |
| Повна інформація про бункер | У настолці бункер-картка описує приміщення, запаси й проблеми — це головний аргумент у дискусії | Дані вже віддавав `/config/bunkers`, тепер показуємо + кількість місць |
| Сповіщення «ваш хід» | Jackbox/skribbl: гравці відволікаються на голосовий чат і пропускають хід | WebAudio-сигнал, вібрація, маркер у заголовку вкладки, вимикач звуку |
| Особисті нотатки про гравців | Гравці в настолку ведуть нотатки на папері; у Spyfall/мафії-клонах є «підозри» | Нотатка на кожного гравця, `localStorage`, бачите лише ви |
| Аватари | Стандарт усіх сучасних лобі | Ініціали на стабільному кольорі з `playerId` |
| Візуалізація голосів | Codenames/мафія-клони показують розподіл голосів | Смуга-заповнення за часткою голосів |
| Поділитися результатом | Wordle-ефект: шеринг підсумку = безкоштовне залучення | Текстовий підсумок (сценарій + хто вижив) |
| Випадковий сценарій одним кліком | Швидкий старт у більшості клонів | Кнопка в лобі власника |

## Що варто зробити далі (потребує бекенда)

1. **Картки особливих умов** — ключова механіка настолки: кожен гравець має
   1–2 карти дій («поміняйся професією з будь-ким», «скасуй голосування»,
   «подивись чужу картку»). Найбільший приріст глибини гри.
2. **Текстовий чат / реакції в кімнаті** — для тих, хто грає без голосового
   зв'язку.
3. **Кік гравця і передача ролі власника** — коли хтось AFK або вийшов.
4. **Глядачі** — підключитись до кімнати, що вже грає, без участі.
5. **Журнал подій** — «Аня відкрила Здоровʼя: Астма», «Богдана вигнано
   3:1»; зручно після реконекту.
6. **Налаштування кімнати** — тривалість ходу, кількість раундів, власні
   набори карток.
7. **Фінальна «історія виживання»** — генерований підсумок, чи вижила
   команда в бункері з урахуванням характеристик (можна через LLM).
